# Day 02 - 조건문과 문자열

> 학습 계획일: 2026-09-05

## 1. if 조건문

조건이 참일 때 코드를 실행한다.

```python
stock = 5

if stock <= 10:
    print("재고 부족")
```

- `if 조건:` 형태로 작성
- `:`을 빼먹지 않기
- 실행할 코드는 들여쓰기하기


## 2. if / elif / else

여러 조건을 위에서부터 순서대로 확인한다.

```python
score = 75

if score >= 90:
    print("A")
elif score >= 70:
    print("B")
else:
    print("C")
```

위에서부터 검사해서 **처음으로 True가 된 코드만 실행된다.**


## 3. 비교 연산자

```text
==  같다
!=  다르다
>   초과
<   미만
>=  이상
<=  이하
```

주의:

```python
a = 10      # a에 10을 저장
a == 10     # a가 10인지 비교
```


## 4. in

문자열 안에 특정 글자나 단어가 있는지 확인한다.

```python
question = "재고가 얼마나 남았나요?"

if "재고" in question:
    print("재고 질문")
```

문자열을 직접 사용할 때는 `"재고"`처럼 따옴표를 사용한다.


## 5. split()

문자열을 나눠서 리스트로 만든다.

```python
text = "사과 바나나 포도"

words = text.split()

print(words)
```

결과:

```text
['사과', '바나나', '포도']
```


## 6. 문자열 자르기

```python
text = "파이썬공부"

print(text[0:2])
```

결과:

```text
파이
```

`[시작:끝]`에서 **끝 번호는 포함하지 않는다.**

```text
파  이  썬  공  부
0   1   2   3   4

text[0:2] → 0번, 1번 → "파이"
```


## 7. 나머지 연산자 %

숫자를 나눈 나머지를 구한다.

```python
number = 10

if number % 2 == 0:
    print("짝수")
else:
    print("홀수")
```

- `10 % 2` → 0
- `11 % 2` → 1

따라서 `number % 2 == 0`으로 짝수를 판별할 수 있다.

# 오늘 어려웠던 점

### 1. `>=` 순서

처음에는 `=>`와 헷갈렸다.

```python
score >= 60
```

처럼 `>=` 순서로 작성한다.


### 2. input()의 결과

`input()`은 항상 문자열(str)로 입력받는다.

숫자 계산을 해야 한다면:

```python
number = int(input("숫자를 입력하세요: "))
```

처럼 `int()`로 변환한다.


### 3. 문자열에는 따옴표가 필요함

```python
if "반품" in question:
```

`"반품"`처럼 직접 작성하는 문자열에는 따옴표가 필요하다.


### 4. 문자열 자르기

처음에는 `split()`과 문자열 자르기를 헷갈렸다.

```python
text.split()
```

→ 문자열을 나눠서 리스트로 만든다.

```python
text[0:2]
```

→ 문자열의 특정 부분을 가져온다.


# 오늘 해결한 방법

- 직접 코드를 작성하고 오류를 수정했다.
- 조건문이 위에서부터 검사된다는 것을 확인했다.
- `input()`으로 받은 숫자를 `int()`로 변환했다.
- `in`을 이용해서 질문에 특정 단어가 있는지 확인했다.
- 문자열 인덱스를 직접 세어보면서 슬라이싱을 연습했다.

```text

```
